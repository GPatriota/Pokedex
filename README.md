# 📟 Pokedex

## 📃 Descrição

Este projeto tem o intuito de fazer algo similar a uma *Pokedex*, que consiga alcançar o objetivo de mostrar todos os Pokemons da primeira geração, onde com o uso de HTML, CSS E JavaScript, seja criada uma tela com os pokemons e exista a possibilidade do usuário carregar novos a partir de um botão.

Para este desafio foram desenvolvidos conhecimentos nas seguintes tecnologias: HTML, CSS e JavaScript.
Além disso, também foi ganho conhecimento em alguns conceitos mais avançados destas linguagens, como requisições de APIs e promises. Inclusive, a requisição neste projeto é feita através da `fetch API`, utilizando a API `pokeapi.co`.
